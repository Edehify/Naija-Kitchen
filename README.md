# Naija Kitchen 🍽️

A modern Nigerian restaurant website showcasing popular Nigerian dishes, traditional meals, and local flavours.

Naija Kitchen is a restaurant website project built as part of **The Odin Project – Full Stack JavaScript curriculum**. The website is designed to help visitors explore the restaurant, discover its menu, and find contact information.

## Project Overview

Naija Kitchen is a fictional Nigerian restaurant based in Warri, Delta State, Nigeria.

The website will feature a clean, responsive design inspired by Nigerian food culture, combining traditional Nigerian cuisine with a modern presentation.

## Features

- **Home Page:** Welcome section introducing the restaurant and showcasing featured dishes.
- **Menu Page:** Displays available meals organised into categories.
- **Category Filtering:** Allows visitors to filter meals by category.
- **Contact Page:** Displays restaurant location, contact details, and opening hours.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Dynamic Navigation:** Switches between Home, Menu, and Contact without reloading the entire page.

## Getting Started

### Prerequisites

- Node.js

Clone the repository:

```bash

```

Navigate into the project directory:

```bash
cd Naija-Kitchen
```

Install dependencies:

```bash
npm install
```
